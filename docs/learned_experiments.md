# 学习型假设实验

这些实现补齐原执行器只支持算术演示的缺口。它们训练实际模型，使用运行期许可反馈，并保存权重、逐种子测量和干预记录。当前仅完成独立试点，不能把代码测试通过写成假设验证通过。

| 假设 | 实现 | 运行期输入 | 主要读出 |
|---|---|---|---|
| H006 历史条件化 | 奖励策略梯度训练 GRU；学习响应头及匹配单网络；冻结参数后打乱、反演历史，钳制、置换路由，测试隐藏切换 | 中性观测、历史动作、历史原生奖励 | 同观测动作分离、错误、切换延迟；评估情境不进入学习 |
| H009 生成重放 | 学习非线性编码器/解码器与潜在混合生成器；持续检测、双候选更新、独立前瞻验收、重校准、有界重试、回滚与未解决后监测 | 实时观测、内部生成样本、固定内部缓冲 | 最新编码器接冻结旧策略的旧关键精度；重建、误报、刷新、实际优化量和覆盖质量 |
| H010 重要性保护 | 用原生奖励学习动作价值；原生能力读出有限差分重要性；联合门控、ST等待、接受后重估、衰减、失败后基础学习 | 候选动作特征、所选动作原生奖励、独立原生能力探针 | 新能力恢复、旧能力保持、状态转移、损毁敏感性、实际 lambda 积分 |

接口统一为 `run_*_seed(seed, config, output_directory) -> dict`。返回 `hypothesis_id`、`seed`、`measurements`、`cpu_seconds`；H009/H010 另返回状态事件、检测或参数轨迹。权重和评估者真值保存在单独文件。真值不作为运行期模型输入。初始化使用标签的 H009 明确记录初始化例外。

安装可选依赖：`pip install -e '.[learned-validation,test]'`。

入口：`python -m scientist.learned_validation --help`。

1. `pilot --output PATH --seed 90`：独立本地试跑；保留 101–120 给后续正式探索实验。
2. `review --request REQUEST_JSON --output REVIEW_DIR`：只把指定的完整 JSON 文件发送给 GLM 5.3；使用结构化审查、缓存与有界重试。
3. `preregister --request REQUEST_JSON --review REVIEW_JSON --output RUN_DIR`：要求三项实现审查均关闭强制修补，且源码和配置没有变更；冻结实验协议、版本、源码哈希、配对种子、效应阈值和预算单位。
4. `run --output RUN_DIR`：执行真实学习实验并逐种子保存不可覆盖的检查点；无演示替代。
5. `replay --output RUN_DIR`：完整重跑每项一个已执行种子，比较除 CPU 耗时外的全部测量；计入计算预算。
6. `analyze --output RUN_DIR`：先用数值代码计算独立种子配对区间及前提检查，再调用 GLM 5.3 解读实测结果。人看的报告简明，详细诊断保存在 JSON。

正式实验仍未执行。全局预算拟定为 1000 个单线程 CPU 秒，必须在预注册中确定后才能使用。远程模型费用单独记录。三项主比较使用 Bonferroni 同时区间；多条流先按独立训练种子聚合，不当作独立训练复现；其余比较为探索性。

必须分别报告更新次数匹配、生成质量及关键/非关键覆盖、无变化与影子刷新误报、重要性损毁相关性、实际保护积分。未满足前提的差异不能当作机制支持或反证。尤其是：重建保持不保证最新编码器—旧策略接口保持；联合门控合法不证明性能更好；未触发的保护策略不能算完成了保护性能验证。局部有限合成任务也不能证明开放环境或生物机理。

本轮生成的实测报告尚未写回研究 SQLite，也未新增支持性实验文献或提高假设状态。完整结果完成审查、复现及结果记录后，再按实际证据推进研究状态。
